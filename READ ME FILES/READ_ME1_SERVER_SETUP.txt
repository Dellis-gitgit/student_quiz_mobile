Στήσιμο Server:

(Σημαντική σημείωση: Όταν θα λέω >> στις εντολές για το terminal μην το γράφετε...
γράψτε απλά ότι έχει μετά απο αυτό π.χ. για το >>python γράφετε μόνο το python)


Το Laptop σου γίνεται ο local web server (Δεν χρειάζεται να έχει ανοιχτό το app)

Εγκατέστισε την python από την επίσημη σελίδα τους άν δεν το έχεις ήδη
https://www.python.org/downloads/


Εφόσον το έχεις ή βεβαιωθείς ότι εγκαταστάθηκε επιτυχώς
(Πήγαινε στο command prompt ή terminal στο search bar στα Windows ή Linux
και γράψε την εντολή >>python 
Θα πρέπει να σου βγάζει την υπάρχουσα εγκατεστημένη έκδοση της
πχ σε εμένα βγάζει Python 3.14.. Έπειτα γράψε >>exit
Από εκεί συνεχίζουμε κανονικά)

Άν έχεις τον φάκελο ολόκληρο στο Desktop θα πατήσεις:

>> cd Desktop 

>> cd student_quiz_mobile

Αυτό θα σε βάλει μέσα στον φάκελο εντός του Terminal

Άν έχεις αποθηκεύσει τον φάκελο οπουδήποτε αλλόυ θα πρέπει να το
καθοδηγήσεις στο συγκεκριμένο σημείο

πχ άν το έχεις απλά στα Downloads θα πρέπει να κάνεις 

>>cd Downloads

>>cd student_quiz_mobile

Έτσι ώστε να καθοδηγήσεις το Terminal στο αρχείο

μετά απο αυτό το dir σου θα πρέπει να μοιάζει κάπως έτσι:

C:\Users\*To όνομα σου στον υπολογιστή.. πχ για εμένα delli*\Desktop\student_quiz_mobile>

Όταν βρεθείς στο σημείο αυτό τότε πας καλά και σου έχει μείνει μονάχα ένα τελευταίο βήμα

>>python -m http.server 8000

Serving HTTP on :: port 8000 (http://[::]:8000/) ...

Θα πρέπει να σου εμφανιστεί αυτό το μύνημα

Άν φτάσεις εδώ τότε συγχαρητήρια, έφτιαξες τον server σου.

ΠΡΟΣΟΧΗ!!!!
Μην κλείσεις το συγκεκριμένο Terminal κατά την διάκρεια της εκδήλωσης
Αν το κλείσεις δεν υπάρχει server και δεν θα μπορεί να συνδεθεί κανένας



Αν θες ο server σου να είναι ενεργός ακόμη και με κλειστή οθόνη
(ΟΘΟΝΗ ΟΧΙ TERMINAL) τότε:

Άνοιξε καινούργιο Terminal χωρις να κλείσεις τα άλλα

>>python -m http:server 8000 --bind 0.0.0.0


Για να κλείσεις τον Server μετά το πέρας της δράσης, απλά κλείσε όλα
τα Terminal.

για να συνδεθούν τα τηλέφωνα
